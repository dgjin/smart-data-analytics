## 简介
本文件面向"智能问数据分析系统"的查询处理引擎，系统性解析 NL2SQL 转换流程、SQL 执行与安全、多轮对话管理、Schema 上下文构建、查询安全防护、分析链（Analysis Chain）工作机制、实时查询（Live Query）流式响应与中断续传等核心能力。**最新更新**：新增P1高级分析能力（时序预测、多维归因、情景推演）和智能体编排系统，提供时间序列预测、多维度贡献度分析、假设情景模拟以及智能Agent的多步骤分析与执行能力。

## 项目结构
查询处理引擎围绕以下关键模块组织：
- 路由层：统一入口、鉴权、限流、SSE 流式事件、推导留痕、缓存命中与降级。
- 编排层：双阶段真实执行（阶段一生成 SQL + 图表配置；阶段二基于真实结果生成解读）。
- **新增P1分析层**：时序预测、多维归因、情景推演三大高级分析能力。
- **新增智能体编排层**：多能力协作规划与顺序执行。
- 安全执行层：SELECT-only、表白名单、敏感列拒绝、行级权限注入、EXPLAIN 防线、连接池与超时控制。
- 上下文层：Schema 加载、范围过滤、敏感列过滤、提示摘要、缓存。
- 分析链：复杂度评估、中间表物化、应用库执行、TTL 清理。
- 知识增强：Few-shot、知识库 RAG、外部知识库、语义指标、个人沉淀、铁律规则。
- 对话历史：服务端落库、窗口清理、个人 few-shot 检索。
- 模板引擎：参数化分析模板，确定性拼装复杂 SQL。

## 核心组件
- 安全执行层：负责 SQL 校验、AST 复核、行级权限注入、EXPLAIN 防线、连接池与超时控制。
- 编排层：实现双阶段真实执行、多候选并行生成与多数表决、澄清/拒答竞速、结果合理性校验与回退。
- **新增P1分析层**：提供时序预测（移动平均/线性回归/季节分解）、多维自动归因（贡献度拆解）、情景推演（SQL改写对比执行）。
- **新增智能体编排层**：LLM驱动的规划器生成多步骤分析计划，顺序执行query/forecast/attribution能力。
- 分析链：对复杂问题自动进行多步清洗，产出中间表并在应用库执行最终查询。

- 对话历史：持久化问答记录，支持搜索、删除与个人 few-shot 自学习。
- 模板引擎：通过轻量 LLM 选择模板并填充参数，确定性拼装复杂 SQL，降低本地模型风险。

## 详细组件分析

### 安全执行层（sqlExecutor）
- 职责：SQL 合法性校验（单语句、只读）、表白名单校验、敏感列拒绝、AST 复核、行级权限注入、EXPLAIN 防线、连接池与超时控制、结果截断。
- 关键点：
  - SELECT-only 与关键字黑名单拦截。
  - AST 解析失败时 fail-closed（WITH 场景），正则防线兜底。
  - 行级权限通过 AST 包裹派生表强制注入，覆盖子查询/CTE/UNION。
  - EXPLAIN 预估扫描行数超阈值则拦截，返回可引导用户收窄条件的提示。
  - 按场景分级连接池与超时（交互/分析链/导出）。
  - MySQL MAX_EXECUTION_TIME hint 注入，PG statement_timeout 配合。

```mermaid
flowchart TD
Start(["进入 executeSafeSql"]) --> Validate["validateSelectSql<br/>单语句/只读/白名单/敏感列/LIMIT"]
Validate --> InjectRow["injectRowFilters<br/>AST 包裹行级权限"]
InjectRow --> Explain{"EXPLAIN 预估扫描"}
Explain --> |超限| Block["guardBlocked=true<br/>返回拦截原因"]
Explain --> |未超限| Exec["执行 SQL(连接池/超时/截断)"]
Exec --> End(["返回 {ok,result}"])
Block --> End
```

### 编排层（liveQuery）
- 职责：双阶段真实执行、多候选并行生成与多数表决、澄清/拒答竞速、结果合理性校验与回退、阶段二解读与降级。
- 关键点：
  - 七路上下文并行加载（few-shot、知识库、外部知识、指标、反例、个人沉淀、铁律）。
  - 模板匹配优先：命中则确定性拼装 SQL，失败回退自由生成。
  - 多候选并行生成（Self-Consistency），结果签名多数表决择优。
  - 数据自省（intermediate_sql）仅首次允许一轮，避免递归拖慢。
  - 空结果跳过阶段二，直接给出真实结论。
  - 阶段二失败时规则化降级解读，保证可用性。

### P1高级分析能力

#### 时序预测（seriesForecast）
- 职责：基于历史时间序列数据进行未来趋势预测，支持多种统计模型。
- 功能特性：
  - 三种预测模型：移动平均（含漂移修正）、线性回归、季节分解
  - 自动模型选择：通过尾部回测按MAPE择优
  - 置信区间计算：基于残差标准差的波动区间
  - 中文诊断：样本量、趋势、季节性、拟合质量说明
- 约束限制：最少3期历史数据，最多24期预测，最大240期历史序列

#### 多维归因（attribution）
- 职责：对指标变化进行多维度贡献度拆解，识别拉高/拉低的关键因素。
- 功能特性：
  - 两期对比：自动取最新两期数据进行环比分析
  - 贡献度计算：delta_i占全部变化量绝对值之和的比重
  - TOP N排序：按|delta|降序排列，识别主要驱动因素
  - 中文诊断：集中度分析、反向维度检测、无效分母提示
- 适用场景：金额、数量、余额等可加指标；比率型需先展开为分子/分母


#### 情景推演（whatIf）
- 职责：基于既有SQL进行假设情景模拟，对比不同条件下的结果差异。
- 工作流程：
  1. 执行原始SQL作为基准

### 智能体编排系统（orchestrator）
- 职责：将复杂分析任务分解为多步骤计划，顺序执行query/forecast/attribution能力。
- 核心流程：
  1. **规划阶段**：LLM根据问题和Schema生成多步骤分析计划
  2. **存储阶段**：计划存储在内存/Redis中，10分钟TTL，一次性消费
  3. **执行阶段**：按步骤顺序执行，上一步结果为下一步输入
  4. **汇总阶段**：生成最终总结和各步骤摘要
- 能力类型：
  - query：通过真实问数链路获取数据
  - forecast：对上游数据进行时序预测
  - attribution：对上游数据进行多维归因分析

## 性能与优化
- 连接池容量公式化：按 EXPECTED_CONCURRENT_USERS 推导，上限保护防打爆数据源。
- 场景化超时与配额：交互/分析链/导出独立配置，避免后台任务挤占交互。
- 多候选并行生成：减少墙钟延迟，澄清/拒答竞速提前返回。
- 模板匹配优先：确定性拼装复杂 SQL，降低本地模型风险与延迟。
- 列级裁剪：宽表 top-N 列注入，降低 prompt token 占用。
- 结果缓存：精确键 + 语义近似命中，显著降低重复提问延迟。
- EXPLAIN 防线：拦截大扫描查询，保护业务库性能。
- 中间表 TTL 清理：定时清理过期中间表，释放存储。
- **新增优化**：P1分析能力采用纯函数实现，无IO依赖，计算效率高；智能体编排支持Redis分布式存储，适合多实例部署。

## 故障排查指南
- 常见错误定位：
  - SQL 被拒绝：检查 validateSelectSql 与 AST 复核原因（非只读/越权表/敏感列）。
  - 执行超时：确认场景超时配置与 MAX_EXECUTION_TIME hint。
  - EXPLAIN 拦截：根据 guardBlocked 提示增加筛选条件。
  - 中间表写入失败：检查列名安全化与配额限制。
  - 阶段二解读失败：查看规则降级输出是否合理。
  - **P1分析错误**：检查输入数据格式、序列长度、模型参数合法性。
  - **智能体编排错误**：验证计划结构、步骤依赖关系、数据源权限。
- 调试工具：
  - 推导留痕：GET /trace/:traceId 回放步骤详情。
  - SSE 断线续传：GET /stream-replay/:traceId?after=seq。
  - 日志与埋点：infra/logger 与 monitoring 埋点观察执行时长与成败。
  - **新增调试**：P1分析接口返回详细诊断信息；智能体编排每步都有summary和error字段。
