- 所有写操作统一通过 store 的 *Remote 方法（如 `updateDashboardWidgetRemote`、`reorderDashboardWidgetsRemote`、`removeDashboardWidgetRemote`）持久化到服务端，失败时静默降级避免 UI 闪断。
- 高频交互（拖拽 mousemove、resize）仅做本地预览（传入 `{ localOnly: true }`），在 mouseup/drop 时才一次性同步远端，减少网络抖动。
- 组件内部状态以 `useState` + `useRef` 组合维护：ref 保存最新快照（如 `widgetsRef`）供异步回调读取，避免闭包过期。
- 金额单位通过 `useEffectiveAmountUnit('dashboard')` 获取模块级覆盖，并在单位切换时清空旧查询结果以保证口径一致。
- 对外部 API 调用统一经 `apiFetch`，错误处理采用 try/catch + 局部状态（如 `metricError`、`error`）展示，不中断主流程。
- UI 文案与行为通过注释标注版本号（如 v0.4.8、v0.9.24、v0.9.34），用于追踪功能演进与兼容性变更。
