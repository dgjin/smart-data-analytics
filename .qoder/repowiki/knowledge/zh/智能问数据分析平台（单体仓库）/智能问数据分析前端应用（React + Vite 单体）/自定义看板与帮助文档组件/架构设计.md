本模块由三个并列的 React 组件构成，均通过 hooks 与 store 交互、通过 apiFetch 调用后端 API，彼此无直接依赖：
- `CustomDashboard.tsx` 是核心看板容器，集中管理 `dashboardWidgets`（来自 `useAnalyticsStore`），实现 HTML5 DnD 拖拽排序、右下角抓手缩放（列宽 1~3 × 高度 200~520px）、三套预设布局（等分三列/双列网格/主图聚焦）；通过 `useDataVersion` 监听数据源指纹变化后重放 `sourceSql` 自动刷新；内置 P2-14 语义指标直查面板，按角色（ADMIN/ANALYST）控制访问，查询结果可一键 `pinChartToDashboardRemote` 固化为图表卡片。
- `AmountUnitSelect.tsx` 是纯展示型通用控件，读取 `useAmountUnitStore` 中全局/模块级单位覆盖，供看板及语义查询面板复用。
- `HelpModal.tsx` 为模态弹窗，内嵌自实现的轻量 Markdown 渲染器（标题/表格/列表/代码块/引用/加粗/行内代码），通过 `/api/help/manual` 与 `/api/help/changelog` 拉取服务端文档并按页签缓存。
依赖方向单向向外：组件 → `hooks/*` 状态库 + `../charts/DynamicChart` + `../../api/client`，不反向依赖业务路由或页面。
