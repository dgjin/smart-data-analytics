入口 `src/main.tsx` 挂载根组件 `App.tsx`，页面骨架由 `components/Header.tsx`、`components/Sidebar.tsx` 提供，各业务域组件按目录划分：admin_panel（运维控制台）、auth（登录/改密）、charts（图表/KPI/表格）、dashboard（自定义看板）、datasource（数据源与知识基座）、flexquery（可视化 SQL 构建器）、help（帮助弹窗）、knowledge（知识管理）、query（对话式查询与会话历史）、reports（报告生成与钻取）。跨组件状态集中在 `hooks/` 下的 Zustand store（useAuthStore、useConversationHistory、useAnalyticsStore、useAmountUnitStore 等），组件仅通过 hook 订阅而非 props 透传；所有后端交互统一经 `api/client.ts` 封装并由 `utils/apiFetch.ts` 提供请求能力，SSE 流式响应由 `utils/sseStream.ts` 处理；可复用算法（flexQueryBuilder、queryResultNormalizer、anomalyDetector、chatRetention、reportPersistence、widgetPersistence、temporalAxis、uiTheme 等）下沉到 `utils/`，被多个子模块共享；各子模块之间不直接耦合，仅通过 hooks、utils 与 api client 通信，从而保证 admin_panel、dashboard、flexquery、query、reports 等可独立演进。
