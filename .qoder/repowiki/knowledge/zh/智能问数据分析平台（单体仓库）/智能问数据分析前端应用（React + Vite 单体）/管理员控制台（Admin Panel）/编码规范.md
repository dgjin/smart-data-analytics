- 每个功能区块封装为独立的 `React.FC` 组件文件，并在 `AdminPanel` 中通过字符串型 `section` 状态条件渲染，新增功能只需新增文件并在容器中添加 tab 分支。
- 数据加载统一遵循「useEffect + setTimeout 延迟调用 + useCallback 包裹 loadXxx + finally 重置 isLoading」模式，避免 effect 内同步 setState。
- 用户反馈统一通过局部 `notice` 状态展示，成功/错误分别用 emerald/rose 配色，并在 4 秒后自动消失。
- 表格类面板使用统一的暗色表格样式：`bg-slate-900 border-slate-800 rounded-2xl shadow-xl`，表头列宽固定并使用 `text-xs`、`font-mono` 呈现 ID/用户名。
- 状态枚举（如 PENDING/APPROVED/REJECTED）集中定义为 `STATUS_META` 映射，包含 label 与 Tailwind 样式类，用于渲染徽章。
- 写操作（创建、启用/禁用、审批、保存配置）统一通过 `apiFetch` 发送 JSON body，并以 `data.success` 与 `res.ok` 双重判断后抛出错误，再由 notice 提示。
