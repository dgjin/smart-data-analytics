模块以 `AdminPanel.tsx` 为唯一容器入口，通过字符串型 `section` 状态在六大区块（基础管理 / 质量监控 / 规则治理 / 权限审批 / AI 审核 / 系统配置）之间切换，每个区块对应一个独立的 `.tsx` 文件并以条件渲染方式引入，形成「单一容器 + 多独立面板」的扁平架构；各子面板之间无直接依赖，仅由容器组合编排。数据访问统一通过项目内 `../../api/client` 的 `apiFetch` 调用后端 REST API（如 `/api/admin/users`、`/api/system/llm-usage`、`/api/access-requests`、`/api/export/requests`、`/api/report-templates`、`/api/admin/env-config` 等），写操作均发送 JSON body 并校验 `res.ok` 与 `data.success`。权限控制复用全局 `useAuthStore` 获取当前用户角色（如 `EnvironmentConfigPanel` 中仅 ADMIN 可见）。UI 风格统一采用 Tailwind CSS 暗色主题（slate-900/950 背景 + indigo/amber/emerald/rose 语义色）与 lucide-react 图标。
