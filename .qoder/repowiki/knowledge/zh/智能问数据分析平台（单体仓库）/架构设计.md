根目录作为单体仓库的装配层：server.ts 启动 Express 服务并挂载 src/ 下由 Vite 构建的前端产物；server/ 按领域拆分为 auth、query、llm、knowledge、report、routes、infra 等子模块，彼此通过共享 infra（db、stateStore、taskQueue、logger、rateLimiter、secretsCrypto）协作，routes/ 仅做 HTTP 路由转发，业务逻辑下沉到对应领域模块；前端 src/ 通过 api/client.ts 调用这些 REST API，状态由 hooks/ 中的 Zustand store 管理。部署层面 deploy/ 提供 Prometheus/Grafana/Alertmanager 配置，docker-compose.*.yml 与 Dockerfile 支持单实例与多实例部署；scripts/ 提供 OpenAPI 同步、数据初始化、评估运行等运维工具；docs/ 集中存放部署指南、架构图与历史交付材料；.agents/skills/archify/ 是独立于主应用的架构文档渲染技能，plugins/ponytail/ 以 skill 形式接入而不侵入核心代码。
