- 服务端按领域划分目录（auth/query/llm/knowledge/report/routes/infra），routes 仅负责参数校验与转发，业务逻辑集中在对应领域模块中。
- 前端组件按功能域组织在 src/components/ 下，公共状态与跨组件能力统一放在 src/hooks/ 与 src/utils/。
- 所有对外 API 通过统一的 api/client.ts 发起请求，避免分散的 fetch 调用。
- 基础设施能力（数据库连接、状态存储、日志、限流、任务队列）集中封装在 server/infra/，业务模块通过导入复用而非自建实现。
- 单元测试与 E2E 测试分别位于各模块同级 *.test.ts 与 tests/e2i/，遵循被测模块就近放置的原则。
