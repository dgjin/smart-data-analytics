模块按职责拆分为四个正交文件，依赖方向单向指向 infra/db、infra/logger、infra/stateStore：
- auth.ts：定义 AuthUser/UserRole 类型并扩展 Express Request；通过 jsonwebtoken 签发/验证 JWT，authMiddleware 在 token 校验后回查 users 表确保禁用/角色变更即时生效，并注入 LLM 用户上下文；requireRole 提供基于角色的守卫。
- passwords.ts：纯函数实现 scrypt 哈希与 verifyPassword，兼容旧 4 段与新 7 段格式，支持可选 SCRYPT_PEPPER pepper，并提供 validatePasswordStrength 弱口令拦截。
- oidc.ts：实现 OIDC 授权码流程（discovery → authorize → exchangeCode → fetchUserInfo），state 票据默认内存 Map、可切换 Redis 以支持多实例；findOrCreateOidcUser 完成 JIT 建号并同步 displayName/department。
- accessControl.ts：基于 data_sources.acl_json 的部门/个人白名单 ACL，canAccessDataSource/checkDataSourceAccess/grantUserAccess/sanitizeAcl 构成从解析、校验到写入的完整链路，与 DataScope 正交。
所有对外能力均以函数形式导出，无全局副作用（除测试用的 resetOidcStateForTest），由上层路由组装为 Express 中间件使用。
