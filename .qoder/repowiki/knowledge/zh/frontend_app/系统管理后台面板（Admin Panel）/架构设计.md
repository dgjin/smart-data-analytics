模块以 `AdminPanel.tsx` 作为唯一入口容器，通过本地 `section` 状态在多个功能区块之间切换（users / quality / usage / metrics / iron-rules / personas / access / templates / env-config），每个区块对应一个独立的 `.tsx` 文件并作为子组件被条件渲染引入。所有子面板均为无路由的纯 React 函数组件，统一通过共享的 `../../api/client` 中的 `apiFetch` 调用后端 REST API（如 `/api/admin/users`、`/api/system/llm-usage`、`/api/access-requests`、`/api/export/requests`、`/api/admin/env-config` 等），并通过 `useAuthStore` 获取当前用户角色进行权限控制（如 `EnvironmentConfigPanel` 中仅 ADMIN 可见）。UI 风格统一采用 Tailwind CSS 暗色主题（slate-900/950 背景 + indigo/amber/emerald/rose 语义色），图标来自 `lucide-react`。模块内各面板之间无直接依赖，仅由 `AdminPanel` 组合编排，形成扁平的“容器 + 多独立面板”架构。
