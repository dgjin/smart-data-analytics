入口 `src/main.tsx` 挂载根组件 `App.tsx`，按业务域在 `components/` 下划分 admin_panel、auth、charts、dashboard、datasource、flexquery、help、knowledge、query、reports 等子模块；跨组件状态通过 `hooks/` 中的 Zustand store（useAuthStore、useConversationHistory、useAnalyticsStore、useAmountUnitStore 等）集中管理，组件仅消费 hook 而非 props 透传；所有后端交互统一经 `api/client.ts` 封装并由 `utils/apiFetch.ts` 提供请求能力，SSE 流式响应由 `utils/sseStream.ts` 处理；可复用算法（flexQueryBuilder、queryResultNormalizer、anomalyDetector、chatRetention 等）下沉到 `utils/`，被多个子模块共享；各子模块之间不直接耦合，仅通过 hooks、utils 与 api client 通信，从而保证 admin_panel、dashboard、flexquery、query、reports 等可独立演进。
