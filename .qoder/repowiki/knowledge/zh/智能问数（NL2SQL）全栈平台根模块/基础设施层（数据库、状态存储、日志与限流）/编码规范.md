- 所有表结构变更使用 `CREATE TABLE IF NOT EXISTS` 配合 `ALTER TABLE` 迁移，并通过捕获 `ER_DUP_FIELDNAME` 保证幂等可重复执行。
- 对外部依赖（Redis、MySQL）采用 `StateStore` 抽象 + 内存/Redis 双实现，运行时依据 `REDIS_URL` 自动切换，测试时可注入 mock 实现。
- 敏感配置（数据源密码）一律通过 `encryptSecret`/`decryptSecret` 以 `enc:v1:` 前缀格式加解密后再落库，存量明文在启动时原地迁移。
- 异步写操作（审计日志、监控埋点）采用 fail-open 策略：写入失败仅记录 warn 日志，绝不阻断主业务流程。
- 环境变量读取统一延迟到函数体内（而非模块顶层），避免 ESM import 提升导致 dotenv 尚未加载的问题。
- 错误响应统一附带 `ERROR_CODES` 中定义的 SCREAMING_SNAKE_CASE 代码字段，前端按 code 分支而非解析中文消息。
