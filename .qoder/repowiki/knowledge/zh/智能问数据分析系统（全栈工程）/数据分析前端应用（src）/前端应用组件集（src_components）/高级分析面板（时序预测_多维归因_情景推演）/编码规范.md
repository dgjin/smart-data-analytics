- 每个视图组件通过 `useMemo` 基于 `widget.data` 计算列特征 profile 与默认列选择，再驱动 `useState` 管理的下拉参数。
- 对外部 API 响应统一采用 try/catch + `resp.ok || data?.ok` 校验，失败时设置 error 状态并清空 result/periods/interpretation。
- LLM 返回的 `interpretation` 字段一律通过 `analysisUtils` 中的 `readStr` / `readStrList` / `readDrivers` 安全读取，避免空引用导致崩溃。
- 数值格式化统一使用模块内 `fmt` 函数（千分位 + 保留两位小数，非有限数显示为 —），正负变化通过 `signed` / `signedPct` 辅助函数处理。
- UI 状态（loading/error/result/interpretation）在每个视图中独立声明，并通过 disabled 属性联动按钮与 select 控件。
- 错误提示、AI 解读、诊断信息等可选内容均以条件渲染包裹，保证在无数据或接口降级时仍可正常展示基础界面。
