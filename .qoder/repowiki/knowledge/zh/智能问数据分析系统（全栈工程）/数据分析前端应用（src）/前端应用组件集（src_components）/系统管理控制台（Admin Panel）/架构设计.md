模块以 `AdminPanel.tsx` 作为唯一路由容器，通过本地 `section` state 在六个分类（users / quality-monitoring / rule-governance / permission-approval / ai-audit / system-config）之间切换，每个分类下挂载一个独立的子面板组件（如 `AccessRequestsPanel`、`LlmUsagePanel`、`MetricsPanel`、`IronRulesPanel`、`ExpertPersonasPanel`、`DlpDownloadPanel`、`EnvironmentConfigPanel`、`FallbackApprovalPanel`、`ABTestDashboard`、`ReportTemplateManager`、`DriftAlertPanel`、`OpsMetricsPanel`）。各子面板均为无状态 React.FC，通过 `../../api/client` 的 `apiFetch` 直接调用后端 REST 接口（如 `/api/admin/users`、`/api/access-requests`、`/api/system/llm-usage`），不共享全局状态；`AdminPanel` 仅负责导航与通知提示（notice 状态 + 4s 自动消失），子面板各自维护自身的数据加载、错误展示与交互逻辑。依赖方向单向：子面板 → api client → 后端 API，子面板之间互不引用。
