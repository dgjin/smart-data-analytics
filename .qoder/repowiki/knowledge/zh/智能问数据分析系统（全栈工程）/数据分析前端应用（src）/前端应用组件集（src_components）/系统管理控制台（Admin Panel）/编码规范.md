- 每个子面板独立实现 `loadXxx` 异步函数并通过 `useEffect` + `setTimeout` 延迟触发，避免在 effect 内同步 setState。
- 所有后端调用统一使用 `apiFetch` 并遵循 `{ success, error }` 响应结构，失败时通过本地 `notice` 状态显示 4 秒自动消失的提示条。
- 表格数据区统一处理三种空态：加载中（旋转图标）、无数据（占位图标+文案）、查询为空（过滤后无匹配），均用 `colSpan` 居中渲染。
- 状态标签（角色、申请状态等）集中定义为 `Record<Status, { label; cls }>` 映射表，按类名动态渲染带边框的胶囊样式。
- 时间字段统一通过 `new Date(x).toLocaleString('zh-CN')` 格式化后再展示。
- 面板头部统一采用 `bg-slate-900 border border-slate-800 rounded-2xl shadow-xl` 卡片风格，配合 lucide 图标与标题副标题布局。
