模块以 React 组件为边界，按职责拆分为六个文件：
- `ReportGenerator.tsx`：报表生成入口，封装模板选择、自定义提示词、金额单位选择、M4 报表计划模式（先 plan 再执行），通过 `/api/report/generate/async` 异步提交任务并用 `pollTask` 轮询结果，结合 `useDataVersion` 实现 live 报表的数据变化自动重生成。
- `ExecutiveReportCard.tsx`：核心渲染层，负责标题/摘要/KPI/洞察/图表组展示、全局主题与同环比对比、本地异常扫描（`scanReportForAnomalies`）、批注协同（双写 store + 本地副本即时回显）、PDF/PPT/Excel/Word/打印导出及图表下钻入口。
- `ChartCommentSection.tsx`：图表级批注面板，按 chartTitle 过滤评论，支持角色切换模拟、新增评论与回复、标记已解决。
- `DrillModal.tsx`：图表点击下钻弹层，调用 `/api/query/drill` 将原 SQL 注入维度条件后拉取明细表。
- `QueryReportCenter.tsx`：问数「报告模式」产出的报告列表与详情视图，复用 `ExecutiveReportCard`，并通过 `pendingReportId` 从对话跳转直入详情。
- `PatrolCenter.tsx`：异常巡检中心，CRUD 巡检计划（`/api/patrols`），启停/立即执行/删除，弹窗展示最近 20 条运行历史及异常明细（Z-Score/阈值异常）。
依赖方向单向向下：所有组件仅依赖 `../../hooks/*`、`../../utils/*`、`../../api/client`、`../../types/analytics` 与同级子组件，不反向引用；状态通过 `useAnalyticsStore`、`useAuthStore` 等全局 store 共享，服务端交互统一经 `apiFetch` 完成。
