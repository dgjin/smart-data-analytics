- 所有网络请求统一通过 `apiFetch` 发起并以 `res.ok` 判断成功，失败时读取 `data.error` 或抛出错误消息展示给用户。
- 长耗时操作（报表生成、巡检执行、导出）采用「提交即返回 taskId → `pollTask` 轮询」的异步任务模式，避免阻塞 UI。
- 用户权限控制通过 `useAuthStore` 获取 `user.role`，对 ADMIN/ANALYST 开放写入能力，VIEWER 角色直接禁用入口并在服务端同样强校验。
- 组件内状态变更采用「先写全局 store 持久化，再同步本地 state 即时回显」的双写模式，保证批注等操作在网络往返期间仍响应迅速。
- 可配置项（模板、金额单位、巡检间隔）以常量数组形式集中声明（如 `templates`、`INTERVAL_OPTIONS`、`AMOUNT_UNITS`），再通过 map 渲染选项。
- 错误与通知统一以带图标的彩色横幅组件呈现，区分 success/error 两类样式，并在超时或操作完成后自动清除。
