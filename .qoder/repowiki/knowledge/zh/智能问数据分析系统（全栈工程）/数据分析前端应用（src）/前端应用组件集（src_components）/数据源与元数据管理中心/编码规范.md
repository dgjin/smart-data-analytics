- 所有网络请求统一封装为 `apiFetch(url, options)` 调用，并在响应中检查 `res.ok` 与 `data.success` 后再执行业务逻辑，错误统一捕获并设置 `actionError`/`error` 状态展示。
- 用户反馈采用顶部通知条模式：成功信息写入 `importNotice`/`notice`，失败信息写入 `actionError`/`error`，并通过 `setTimeout` 自动清除，避免手动关闭。
- 可复用的模态弹窗（ACL、问数范围）拆为独立 `.tsx` 文件，仅接收受控 props（ds、saving、onSave、onClose 等），不持有自身业务状态，由父组件管理数据源引用与保存流程。
- 按钮与工具提示组合采用自定义 `TipAction` 包裹，使用 Tailwind `group-hover/tip` 实现纯 CSS 气泡提示，替代原生 title，提升深色主题下的可读性。
- 数据源卡片上的多个操作按钮（范围配置、指标维护、自省开关、同步、ACL、删除）统一通过 `e.stopPropagation()` 阻止冒泡，避免误触外层卡片的选中行为。
