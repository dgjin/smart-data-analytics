- 组件以 `export const Xxx: React.FC = () => {...}` 形式导出，props 通过接口或解构声明，避免类组件。
- UI 文案与样式统一采用 Tailwind 原子类组合，深色主题下使用 `bg-slate-900/950`、`border-slate-800`、`text-slate-200` 等语义化配色。
- 异步操作统一通过 `apiFetch` 发起，成功/失败分支用 try/catch 包裹并通过本地 `useState` 设置 `error`/`isSubmitting` 等反馈状态。
- 权限控制通过 `useAuthStore` 读取 `user.role` 后条件渲染导航项或功能入口（如 VIEWER 隐藏 query/datasources/admin）。
- 需要持久化的用户偏好（如侧边栏折叠态）使用 `localStorage` 读写，并对外部存储不可用做 catch 降级。
- 弹窗/模态组件通过 props 传入 `onClose` 回调并由父组件维护打开状态，不在组件内部自行管理可见性。
