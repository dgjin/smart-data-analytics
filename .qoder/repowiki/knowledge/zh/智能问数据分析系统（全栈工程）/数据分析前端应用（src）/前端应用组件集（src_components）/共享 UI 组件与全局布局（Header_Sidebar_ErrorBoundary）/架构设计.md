本模块按职责划分为三层：
- 全局壳层：`ErrorBoundary.tsx` 作为根级 React 错误捕获容器，防止单组件崩溃导致整页白屏；`Header.tsx` 与 `Sidebar.tsx` 构成应用主框架，通过 `useAnalyticsStore`、`useAuthStore`、`useEngineInfo` 等 hooks 读取全局状态并驱动 Tab 切换、数据源切换、主题切换与导航项权限过滤（VIEWER 仅看报表/看板/巡检）。
- 认证入口：`auth/Login.tsx` 与 `auth/ForceChangePassword.tsx` 分别处理普通登录与首登强制改密流程，均调用 `apiFetch` 对接 `/api/auth/*`，并在 OIDC 启用时展示企业统一登录入口。
- 功能型共享面板：`help/HelpModal.tsx` 内置轻量 Markdown 渲染器，动态拉取 `/api/help/manual` 与 `/api/help/changelog` 并以标签页展示；`dashboard/CustomDashboard.tsx` 实现固化图表网格编排（HTML5 DnD + 鼠标缩放），通过 store 的 `*Remote` 方法持久化布局并支持数据指纹变化自动重放 SQL；`knowledge/KnowledgeManagementPanel.tsx` 提供知识库 JSON 导入/导出及冲突策略；`common/AmountUnitSelect.tsx` 暴露模块级金额单位覆盖选择器，配合 Header 的全局单位形成「全局默认 + 模块覆盖」的双层口径体系。
依赖方向单向向下：所有组件通过 `../hooks/*` 与 `../api/client` 访问状态与后端，不反向引用业务页面，保证可被任意 Tab 复用。
