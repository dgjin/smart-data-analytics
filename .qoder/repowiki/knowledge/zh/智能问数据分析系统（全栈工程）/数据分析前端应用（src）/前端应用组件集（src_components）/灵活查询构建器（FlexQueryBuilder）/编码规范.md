- 字段列表项同时支持点击直接添加与 hover 时出现的快捷 Filter/Plus 按钮，用于快速加入维度、指标、WHERE 或 HAVING，避免长距离拖拽。
- 所有持久化操作（保存/删除固定报表、写入查询历史）采用乐观更新：先修改本地 state，再异步调用 API，失败时回滚并 toast 提示。
- 可折叠区域（高级筛选、SQL 预览、维度/指标分组）统一使用 `setXxxOpen` 布尔状态配合 ChevronUp/ChevronDown 图标切换展开态。
- 拖放区通过 `dragOverZone` 状态 + `zoneClass` 函数动态切换边框高亮与背景色，`handleDrop` 统一解析 `text/plain` 字段名后委派到 `addField`。
- 跨表字段在字段列表中用 `table !== selectedTable` 判断并前置 `[表名]` 前缀，同时在 `allFields` 中维护 `fullName = table.column` 以区分来源。
- 金额单位切换时通过 `useEffectEffectiveAmountUnit('flexquery')` 获取模块级覆盖值，并在 SQL 构建期按 `AMOUNT_UNIT_DIVISORS` 换算，列名追加 `（单位）` 标注口径。
