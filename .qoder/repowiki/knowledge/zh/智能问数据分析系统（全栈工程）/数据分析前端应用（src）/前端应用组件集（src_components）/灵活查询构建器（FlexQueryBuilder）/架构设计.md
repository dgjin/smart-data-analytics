模块以 `FlexQueryBuilder.tsx` 为唯一容器组件，集中管理数据源 Schema 加载、查询配置状态（dimensions/measures/filters/havings/orderBy/joins）、SQL 构建与执行结果；通过 `useMemo` 将配置组合为 `FlexQueryConfig` 并调用 `utils/flexQueryBuilder.buildFlexQuerySql` 生成 SQL，再经 `/api/query/execute-sql` 执行。

子组件按职责拆分：
- `JoinConfigPanel.tsx`：封装多表 JOIN 的表选择、类型（INNER/LEFT）与 on 条件下拉，仅在主表 Schema 存在时渲染。
- `SqlPreviewPanel.tsx`：可折叠的 SQL 实时预览面板，根据 `FlexBuildResult.ok` 显示成功 SQL 或错误信息。
- `FlexQueryLibrary.tsx`：左右双栏面板，分别展示「已保存固定报表」和「最近查询历史」，通过回调与父组件交互。

依赖方向单向：本模块依赖 `../../utils/flexQueryBuilder`（类型与 SQL 构建）、`../../hooks/useAnalyticsStore`（数据源与看板固化）、`../../api/client`（HTTP 请求），不反向被其他业务模块引用，属于纯前端 UI 叶子模块。v0.9.24 起引入服务端持久化迁移逻辑，启动时把 localStorage 中的旧数据推送到 `/api/flex-queries` 与 `/api/flex-queries/history`，再以服务端权威数据覆盖本地状态。
