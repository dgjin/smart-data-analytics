本模块以 React + recharts 为核心，按职责拆分为四个独立组件：
- `DynamicChart.tsx`：核心渲染器，通过 `config.type`（bar/line/area/pie/donut/radar/scatter/treemap/heatmap）在单一组件内分发到不同 recharts 子图；内置缩放刷（Brush）、滚轮缩放、同比/环比（YoY/MoM）对比计算、差异百分比徽标、主题切换与自动对比度优化，并通过 `data-chart-capture-root` 标记供 PDF/PPT 导出快照。
- `ChartCustomizer.tsx`：纯 UI 配置面板，暴露 `config` + `onChange` 回调，允许切换图表类型与堆叠模式，并可选触发 `onPinToDashboard` 固定看板。
- `DataTable.tsx`：前端分页、搜索、排序的数据明细表，CSV 导出统一走 `downloadServerCsv` 服务端通道以嵌入溯源水印与审批流程。
- `KPIStats.tsx`：轻量 KPI 卡片网格，根据 `trend/change` 展示涨跌徽标。
依赖方向单向向下：组件仅消费 `../../types/analytics`、`../../utils/chartThemes`、`../../utils/temporalAxis`、`../../hooks/useAnalyticsStore` 等共享能力，不互相引用，便于单独复用。
