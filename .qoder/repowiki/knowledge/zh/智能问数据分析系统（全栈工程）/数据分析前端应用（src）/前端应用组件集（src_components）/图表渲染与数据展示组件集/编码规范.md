- 数值格式化统一使用 `toLocaleString()`，整数千分位、非整数补足两位小数且不补零，避免二次缩写万/亿以免与 SQL 侧单位冲突。
- 图表交互状态（缩放起止索引、对比模式、主题、徽标显隐）全部以本地 `useState` 维护，props 变更通过 `useEffect` 同步回写内部状态。
- 同/环比仅在时间序列 x 轴且存在真实历史基线时启用，缺失基线的点保持 `undefined` 不编造数据，并通过 `_prior` / `_diff_pct` 字段追加到行对象。
- 所有图表根节点添加 `data-chart-capture-root` 属性，以便报表导出按 DOM 原样快照并与 charts 数组一一对齐。
- 饼/环形图显式关闭动画（`isAnimationActive={false}`），避免父组件重渲染导致 label 隐藏影响导出快照。
- 表格列名优先取 `columnNames` 中文映射，原始列名通过 `title` 悬浮提示保留，实现业务语义与物理键解耦。
