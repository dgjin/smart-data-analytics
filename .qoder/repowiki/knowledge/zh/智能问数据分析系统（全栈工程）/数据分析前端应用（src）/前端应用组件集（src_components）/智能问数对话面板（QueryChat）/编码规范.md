- 所有用户可持久化的模式开关（计划模式、Agent 编排、深度分析、报告模式、模型选择）均以 `localStorage` 键值存储，并在组件初始化时读取默认值，异常时降级为 false。
- 对外部 API 调用统一通过 `apiFetch` 发起，并以 try/catch 包裹后通过 `addChatMessage` 写入错误消息，保持错误路径与成功路径同构。
- 模态框/弹出面板采用「受控 isOpen + 点击外部关闭」模式，通过 `ref` 监听 document mousedown 实现点击空白处收起（见 SkillMenuButton）。
- SSE 流式处理在 `QueryChat` 中集中编排，通过 `readSseStream` 的 onStage/onChunk/onTerminal 回调分别更新进度、流式内容与终态结果，并支持基于 traceId 与事件序号的断线续传。
- 子组件普遍以 props 形式接收行为回调（如 onTogglePlanMode、onSelectModel、onClose），将状态与副作用留在父组件 QueryChat，子组件保持纯展示职责。
- 样式统一采用 Tailwind 暗色主题（slate-900/950 背景、indigo/emerald/rose 语义色边框与文字），并通过 hover 态与禁用态（disabled:opacity-50）表达交互反馈。
