组件按业务域以子目录组织：admin（管理控制台）、analytics（高级分析）、auth（认证）、charts（图表渲染）、datasource（数据源与元数据）、flexquery（灵活查询构建器）、query_chat（智能问数对话）、reports（报表与巡检）、shared_ui（全局布局与通用组件）。各域之间通过共享的 charts 可视化能力与 shared_ui 的全局布局进行松耦合协作——例如 flexquery、query_chat、reports、analytics 均复用 charts 中的 DynamicChart/KPIStats/DataTable 呈现结果，同时由 Header/Sidebar/ErrorBoundary 统一包裹页面级组件；datasource 作为数据底座被 flexquery 与 query_chat 消费，形成「数据源 → 查询/对话 → 可视化/报表」的单向依赖链。跨域通信主要依赖各自暴露的 props 与事件回调，而非集中式状态总线。
