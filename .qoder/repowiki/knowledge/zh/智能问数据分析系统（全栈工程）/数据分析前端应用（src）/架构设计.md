入口 main.tsx → App.tsx 负责挂载根组件、初始化主题与鉴权，并按角色/标签页渲染子模块；components 下按业务域（admin/analytics/auth/charts/datasource/flexquery/query/reports 等）拆分 UI，统一通过 hooks 中的 zustand store 共享全局状态（认证、对话历史、数据源、引擎信息等），并通过 utils 提供的 apiFetch、SSE 流解析、SQL 构建、结果归一化等纯函数与后端交互；api/client.ts 作为统一的 HTTP 客户端被各组件与 Hook 调用，types 集中声明跨模块共享的 TS 类型，形成「UI 组件 → Hook/Store → utils/api → 后端」的分层依赖关系。
