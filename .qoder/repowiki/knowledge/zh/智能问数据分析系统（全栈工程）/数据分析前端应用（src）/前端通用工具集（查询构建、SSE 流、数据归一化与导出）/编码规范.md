- 对外暴露的构建/解析函数统一返回 `{ ok: true, ... } | { ok: false, error: string }` 的联合类型，由调用方集中处理错误分支。
- 所有用户输入在拼入 SQL 前必须经过标识符白名单校验（`IDENT_RE`）与字符串字面量单引号加倍转义，禁止直接拼接原始值。
- 对 LLM/外部不可信 JSON 一律先 stripCodeFences 再 safeParseJson，并对字段做类型收窄与默认值回退，避免裸 `JSON.parse` 信任模型输出。
- 网络请求统一通过 `apiFetch`（或 `../api/client` 的 `apiFetch`）发起，不在工具内部自行调用 `fetch`，以便复用鉴权与错误处理。
- 每个工具模块配套同名 `.test.ts` 单元测试文件，与实现文件并列存放，覆盖核心边界条件。
- 时间/数值类输入采用保守识别策略：无法明确识别时返回 null/false，宁可降级也不误判（如 `detectTemporalAxis`、`filterValueToSql`）。
