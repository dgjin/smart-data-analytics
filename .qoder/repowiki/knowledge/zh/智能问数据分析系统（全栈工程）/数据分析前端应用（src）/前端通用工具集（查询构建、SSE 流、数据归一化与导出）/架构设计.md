本模块按职责横向切分为若干独立工具文件，每个文件暴露一个或多个纯函数或轻量封装，不持有全局状态，依赖方向单向指向 `../api/client`（`apiFetch`、`parseApiErrorBody`）和 `../types/analytics`。
- SQL 构建：`flexQueryBuilder.ts` 定义 `FlexQueryConfig`/`FlexFilter`/`FlexHaving`/`FlexJoin` 等类型，通过 `buildFlexQuerySql` 将配置安全拼接为 SELECT/GROUP BY/HAVING/ORDER BY/LIMIT 语句，并对标识符做白名单校验、字符串单引号转义，作为客户端第一道防注入防线；`sqlLineage.ts` 用正则从 SQL 反向提取 JOIN 链用于可视化溯源。
- 流式交互：`sseStream.ts` 基于 `ReadableStream` + `TextDecoder` 逐块解析 `text/event-stream`，按 `event:`/`data:`/`id:` 行分发到 `onStage`/`onChunk`/`onTrace`/`onTerminal`/`onEventId` 回调，并区分业务终态错误（标记 `sseTerminal`）与可续传的网络中断。
- 长任务：`asyncTask.ts` 封装提交后轮询 `/api/tasks/:id` 的 `pollTask`，支持连续失败重试与超时，并提供 `downloadTaskResult` 下载 PDF 等二进制结果。
- 数据归一化：`queryResultNormalizer.ts` 统一清洗 LLM 返回的 JSON（剥离 markdown fence、兼容 `data`/`rows`、校验 chartConfig），`temporalAxis.ts` 判定 x 轴是否为时间序列以启用同比/环比。
- 导出与持久化：`exportCsv.ts` 统一走服务端 `/api/export/csv` 带水印审计；`reportPersistence.ts`、`widgetPersistence.ts`、`chatRetention.ts`、`reportRegen.ts`、`dataVersionWatcher.ts` 分别负责报告/组件/会话/版本变更的本地存储与监听。
- 辅助：`apiFetch.ts` 是内联的轻量 fetch 封装（默认 `application/json`、非 2xx 抛错）；`chartThemes.ts`、`uiTheme.ts` 提供主题常量；`anomalyDetector.ts`、`querySuggestions.ts` 提供异常检测与建议生成。
