本模块由四个顶层文件构成应用启动壳：`src/main.tsx` 作为 Vite 入口，通过 `createRoot` 在 `<StrictMode>` + `<ErrorBoundary>` 中挂载 `App`，并在挂载前调用 `applyUITheme(getUITheme())` 同步持久化主题，同时通过 `configureApiAuth` 将 `useAuthStore` 的 token、登出、强制改密回调注入到 API 客户端层，实现跨 store 解耦；`src/App.tsx` 是根组件，组合 `Header`、`Sidebar` 与右侧内容区，基于 `activeTab` 使用 `switch` 分发到 `QueryChat`、`ReportGenerator`、`CustomDashboard`、`FlexQueryBuilder`、`DataSourceManager`、`AdminPanel`、`PatrolCenter` 等页面，并通过 `user.role`（VIEWER/ADMIN）做越权守卫，所有大组件采用 `lazy()` + `Suspense` 懒加载以减小首屏体积；`src/index.css` 基于 Tailwind v4 的 `@import "tailwindcss"` 引入样式，并通过 `html.light` 选择器重映射 slate/indigo/cyan/violet/emerald/rose/amber/sky 等 CSS 变量实现浅色主题切换；`src/vite-env.d.ts` 声明 `VITE_APP_VERSION` 环境变量类型，供界面展示版本号。依赖方向单向：main → App → 各业务组件，API 客户端通过配置函数反向获取 auth store 状态，避免循环依赖。
