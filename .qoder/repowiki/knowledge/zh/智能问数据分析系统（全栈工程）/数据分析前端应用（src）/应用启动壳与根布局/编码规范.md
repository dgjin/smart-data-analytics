- 大体积业务组件统一通过 `lazy(() => import(...))` 懒加载并在 `Suspense` 中包裹，以减少首屏 bundle 体积。
- 权限控制集中在 `App` 根组件内，依据 `user.role`（VIEWER/ADMIN）对 `activeTab` 进行守卫并回退到默认看板页。
- 全局副作用（SSO 回跳、数据源加载、主题应用、API 鉴权注入）统一放在 `main.tsx` 或 `App` 的 `useEffect` 中集中处理，避免分散在各子组件。
- 样式主题通过 Tailwind CSS 变量覆盖实现，深色为默认主题，浅色模式仅在 `html.light` 下重映射色值，保持零改动兼容。
