本模块按职责拆分为两类文件：
- Zustand store 型 hook（useAnalyticsStore、useAuthStore、useAmountUnitStore）：通过 `create` + `persist` 中间件维护跨组件全局状态，使用 `partialize` 控制持久化字段并配合 `migrate`/`version` 做本地存储版本升级；其中 useAnalyticsStore 是核心聚合 store，集中管理数据源、NL 对话、看板 widget、已保存报表及评论等，并通过会话内防重入 Promise（`savedReportsInitPromise`、`dashboardWidgetsInitPromise`）保证初始化幂等。
- 纯函数型 React Hook（useConversationHistory、useDataVersion、useEngineInfo、useModelCatalog、useSpeechInput）：封装特定业务能力的副作用逻辑，依赖 `../api/client` 的 `apiFetch` 访问后端 REST 接口，通过 `useState`/`useEffect`/`useRef` 管理本地 UI 状态与生命周期。
依赖方向单向向下：hooks → `src/api/client`、`src/types/analytics`、`src/utils/*`，不反向引用页面组件，从而可被任意组件复用。
