根目录作为全栈编排层：server.ts 启动 Express 服务，挂载 src/ 下的 React 前端静态资源与 server/ 下的业务路由；server/routes/* 将 HTTP 请求分发到 server/{auth,agent,llm,query,knowledge,report,analytics,infra} 等子模块，形成「前端组件 → API Client → Express 路由 → 领域服务 → 基础设施」的单向调用链。跨子模块的横切能力集中在 server/infra（MySQL、状态存储、限流、任务队列、审计日志、加密）、deploy/ 下的 Prometheus/Grafana/Alertmanager 监控栈，以及 scripts/ 中的 OpenAPI 同步与数据初始化脚本。前端 src/components/* 按业务域组织并通过 hooks/utils 复用状态与工具，测试用例分别位于 test/、tests/e2e/ 与各子模块同级 *.test.* 文件，CI 由 .github/workflows/ci.yml 统一触发。
