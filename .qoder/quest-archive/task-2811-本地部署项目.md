## 四、本任务中的关键决策（已沉淀为记忆）

1. 本地 Ollama 为默认主引擎，云端模型按需切换（禁用 deepseek-r1:8b 作主模型规避推理链超时）
2. 双阶段真实数据回喂架构（LLM 不接触数据，杜绝编造）
3. 拒答优先于胡答（诚实性设计）
4. 金额单位跨链路统一（report / dashboard / 归因全链路）
5. 每次优化验证通过后自动提交双远程（GitHub + Gitee 镜像）
6. 简化修改一次最小修复 + 轻量验证（反对反复浏览器验证消耗 credits）
7. P2-14 成本治理不实施（本地算力场景无 token 成本压力）
8. 报告链路单位对齐采用"三端点统一支持 amountUnit"而非仅修主路径
