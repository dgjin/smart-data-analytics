运行环境要求:
- Node.js >= 18
- MySQL 8 (系统元数据库)
- 可选: Redis (用于限流/缓存状态同步), Python 3 + ReportLab (PDF导出)

关键环境变量:
- JWT_SECRET: 生产环境必填，缺失则拒绝启动
- MYSQL_HOST/PORT/USER/PASSWORD/DATABASE: 数据库连接
- LLM_MODEL: AI推理模型 (默认 deepseek-r1:32b)
- OLLAMA_URL: Ollama 服务地址
- QWEN_API_KEY/GEMINI_API_KEY: AI引擎密钥
- ADMIN_USERNAME/PASSWORD: 初始管理员账号

启动端口: 默认 3000
