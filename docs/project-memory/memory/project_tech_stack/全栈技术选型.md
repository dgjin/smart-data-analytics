开发语言: TypeScript (~5.8.2)

后端技术:
- 框架: Express 4
- 运行时: Node.js (tsx 开发 / esbuild 打包)
- 数据库: mysql2 (MySQL), pg (PostgreSQL/Greenplum)
- AI集成: @google/genai (Gemini), node-sql-parser
- 缓存/状态: ioredis (Redis)

前端技术:
- 框架: React 19 + TypeScript
- 构建: Vite 6
- UI库: Tailwind CSS 4, Recharts (图表), motion (动画), lucide-react (图标)
- 状态管理: Zustand

测试与工具:
- Vitest, Playwright, ESLint
