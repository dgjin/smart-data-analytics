构建命令 (npm scripts):
- `npm run dev`: 使用 tsx 启动开发服务器
- `npm run build`: 执行 `vite build` 打包前端，然后使用 `esbuild` 将 server.ts 打包为 dist/server.cjs
- `npm start`: 生产环境启动，运行 `node dist/server.cjs`
- `npm test`: 运行 Vitest 单元测试
- `npm run lint`: TypeScript 类型检查

构建细节:
- 后端使用 esbuild 进行 bundle 打包，输出 CommonJS 格式
- 前端使用 Vite 构建，支持 HMR
