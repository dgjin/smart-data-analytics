# 智能问数分析系统 · 更新日志

> 本日志按版本记录系统的主要更新内容，供用户备查。各版本的具体操作方法见「使用指南」；完整技术细节见《系统功能说明书》变更记录（仅供管理员与评审参考）。

## v0.9.90（2026-09-29）

- **帮助中心检索体验优化：搜索更稳、不再闪跳**：
- **搜索不再闪烁**：连续输入关键词时，已给出的结果保持展示（列表上方提示「正在搜索」），新结果到达后原地更新——不再出现「结果与加载动画反复替换」的闪动。
- **清空搜索回到原处**：在文档里看到一半去搜索，清空关键词（或按 Esc）后回到原来的阅读位置，不再跳回文档顶部。
- **输入更顺滑**：检索时的文档重绘开销大幅降低，长文档（更新日志）下输入也不卡顿。

## v0.9.89（2026-09-29）

- **帮助中心支持「模块抽屉」与关键词搜索，查文档更省事**：
- **模块抽屉收起展示**：打开右上角「帮助」，使用指南的每个大节、更新日志的每个版本都以可折叠的「抽屉」呈现——默认只展开第一个模块，点标题即可展开 / 收起，右上角还能一键「全部展开 / 全部收起」，长文档不再一滚到底。
- **搜索框快速定位**：页签右侧新增搜索框，输入关键词（如「数据源」「导出 PDF」「审批」）即可跨「使用指南 + 更新日志」同时搜索；结果显示所属文档、模块名与摘要片段（命中词高亮），点击一条自动跳到对应页签、展开命中模块并定位高亮，找内容不用再逐节翻。
- **小提示**：搜索状态下按 Esc 先清空关键词，再按一次则关闭帮助面板。

## v0.9.88（2026-09-29）

- **帮助面板新增「智能问答」：系统用法直接用中文问 AI**：
- **提问即答**：打开右上角「帮助」→「智能问答」页签，像聊天一样提问（如「怎么配置数据源」「金额单位在哪里设置」「为什么图表不能做同比」），AI 基于使用指南与更新日志快速作答，并附「参考」章节便于回看原文。
- **支持连续追问**：可接着追问（如「那审批呢？」），AI 结合上文理解你的指代，不必重复描述；内置几条常用问题可一键发起，对话可随时清空重来。
- **回答有据可依**：AI 只依据系统帮助文档作答，文档未覆盖时会明确说明并建议到「使用指南」页签查阅，不会编造功能。

- **「首启初始化向导」图形界面正式上线**：
- **开箱即用、全程可视**：系统新部署后，管理员首次打开系统会自动进入五步初始化向导（环境检测 → 模型服务 → 数据自动准备 → 待办事项 → 完成），从环境自检、数据源接入到知识与样例准备一站式跑通；每步可跳过，中途退出后再进入自动回到上次位置（断点续做），不影响其他功能使用。

- **常驻入口与系统体检**：选择「暂不配置」后，页面顶部横幅持续显示自动准备进度，7 天内部再打扰；之后随时可在「系统管理」首屏的「首启初始化向导」卡片继续配置。完成初始化后，该卡片自动转为「系统体检」，一键复检环境与知识资产的就绪状态。

## v0.9.83（2026-09-29）

- **新数据源「接入即就绪」：知识与样例自动准备**：
- **不用再手工补录**：保存数据源后，系统自动把每张表的结构（表含义、字段含义与角色）与自动生成的业务说明建立成问数可检索的知识，并按表结构预置一批标准 SQL 样例（趋势、排名、最新快照等写法）——接完就能直接问，获得贴合表结构的 SQL 与解读。
- **知识自动跟随更新**：重新同步 Schema 或编辑数据源时，知识与样例同步刷新，不再存在的表结构说明自动清理，不留旧内容。
- **导入脚本更通用了**：命令行导入复杂 SQL 样例的脚本可用环境变量 `DATASOURCE_ID` 指定目标数据源（不再写死）。

## v0.9.80（2026-09-28）

- **灵活查询·表关系画布「字段图形化」**：
- **字段看得更清**：画布里的字段从文字行升级为图形化字段片——每种类型一个专属色块图标（文本 / 分类 / 数值 / 日期 / 布尔一色一形），主键与「已使用」都有徽章标注，字段属性一眼可辨。

## v0.9.78（2026-09-27）

- **问数知识检索升级（中文语义 + 双通道融合）**：
- **中文语义更准**：知识检索换用中文专用向量模型（qwen3-embedding），此前中文场景下「相关」与「无关」内容区分度不足的老问题已修复；历史知识已自动重嵌完成，无需手工操作。
- **精确术语不再漏**：指标名、枚举值等与问题字面精确对应的业务条款，即使语义相似度偏低也会被召回（向量 + 关键词双通道融合排序），口径类知识命中更稳。
- **无关问题不再注入噪声**：问与业务数据无关的问题（如「今天天气怎么样」）时不再塞入无关业务条款干扰回答；涉及数据安全的高危指令（如「删数据」）仍由问数链路的拒答机制兜底（知识检索层不作唯一防线）。
- 管理员提示：本版附带 31 条检索回归评测（`npm run eval:retrieval`，当前命中率 92.9%）；若自行更换向量模型，必须运行 `npm run reembed:embeddings` 重嵌历史知识（自动备份，可回滚）。

## v0.9.77（2026-09-27）

- **灵活查询八项增强（一次交付）**：
- **计算字段**：在指标结果列上自定义计算列——如「单均价 = 金额 ÷ 数量」，在「计算字段（指标结果列上的表达式）」区块点「+ 添加计算字段」，表达式引用指标结果列别名（界面下方会列出可引用别名清单）；支持四则运算、括号、比较与 IF 条件及 ROUND / ABS / LEAST / GREATEST / NULLIF / COALESCE 函数，最多 4 个，保存前自动校验；计算列可参与排序与图表展示。
- **选表即预览**：选中数据表后点「预览数据」即可内联查看样例数据（前 10 行，敏感列已自动剔除），选字段前先看清数据长什么样。
- **字段拼音搜索**：字段搜索框支持拼音首字母——输入 `jgmc` 直接命中「机构名称」，中文、拼音、混合输入均可匹配。
- **Excel 导出（固定报表）**：固定报表卡片新增「导出 Excel」——由服务端按报表定义重跑查询（数据完整，不受页面行数限制），文件带溯源水印（导出人 + 严禁外传提示）、深色表头与自适应列宽，导出行为记入审计日志。
- **预估扫描行数**：查询执行后展示 EXPLAIN 预估扫描行数；预估超过 10 万行时琥珀色高亮并提示「建议收窄筛选条件」。
- **图表扩展**：新增 KPI 卡片（大字报数）与散点图；柱状 / 折线 / 面积图支持「堆叠」（多指标同轴叠放）与「双轴」（第 1 指标左轴、第 2 指标右轴）开关，金额与率值可同图对比。
- **版本历史与回滚**：固定报表每次保存自动留存快照（含修改说明）；点报表卡片「版本历史」可查看全部版本并一键回滚，回滚本身也会生成新版本，可再回退。
- **报表订阅与告警**：固定报表可创建订阅——按周期（5 分钟 ~ 7 天）自动重跑，指标突破阈值（如「不良率 > 5」）时记录告警；支持暂停 / 恢复、立即执行一次与运行历史（状态、行数、告警值、耗时），入口为固定报表卡片「订阅」按钮。

## v0.9.76（2026-09-27）

- **灵活查询六项增强（一次交付）**：
- **语义指标直接入列**：管理员在「系统管理 → 规则治理 → 语义指标」定义的口径（如不良率、人均产能等）可直接加入灵活查询的指标区——点击字段面板「语义指标」区块即可添加，取数口径与全系统报表完全一致；指标绑定归属表（含固定过滤条件），选择前会校验数据表一致性。
- **同比 / 环比 / 累计 / 移动平均**：日期字段选择统计粒度（按年 / 季 / 月 / 周 / 日）后，「时间衍生列」区可一键为任意指标添加同比、环比、累计、移动平均（2~12 期可选）列，无需自己写窗口函数；衍生列可与维度、其他指标自由组合，图表与 CSV 导出同步可用。
- **结果缓存与执行取消**：同一查询（同数据源同 SQL）在 10 分钟内重复执行直接秒回缓存结果，结果区标注「缓存命中」；点「强制刷新」可跳过缓存重新查询；查询执行中可随时点「取消」停止等待（后台任务仍会继续执行，可在任务中心查看）。
- **后台执行（大查询）**：勾选「后台执行（大查询）」后查询转入任务队列执行，不再受 10 秒交互超时限制、不阻塞页面；执行完成后结果自动回填到结果区，也可从任务中心随时查看结果。
- **OR 条件组**：高级筛选新增「OR 条件组」——如要看「华东或华南」的数据，可把多个条件放进一组（组内任一满足），多组之间仍是 AND 关系；最多 5 组、每组 5 条。
- **图表下钻**：灵活查询的图表（柱状图 / 折线图 / 面积图）支持点击柱体 / 数据点下钻，弹出该维度的明细数据（最多 50 行），与报表下钻体验一致。

## v0.9.75（2026-09-27）

- **灵活查询六项体验升级（一次交付）**：
- **时间维度任意粒度**：日期字段加入「分组维度」后，可在字段下方选择统计粒度（按年 / 按季度 / 按月 / 按周 / 按日，默认原值），同一字段换粒度即换统计口径，无需改数据。
- **筛选更贴合业务习惯**：日期字段可直接点选「今天 / 近 7 天 / 近 30 天 / 本月 / 本季 / 今年」快捷区间（自动转为起止区间筛选）；数值字段选「区间」时为上下限双输入框；文本筛选可选匹配方式——包含 / 开头是 / 结尾是 / 精确匹配；机构、状态等常用分类字段可从下拉直接点选真实取值（服务端安全探测，最多 100 个候选值，超出自动截断提示），不再靠手敲。

- **合计行**：结果表可一键显示「合计」行——求和类指标自动相加、最大 / 最小取极值，比例与去重计数类指标显示「-」；结果被行数上限截断时自动隐藏合计并提示（避免不完整数据被误读为总额）；「CSV 导出」同步包含合计行。
- **固定报表检索与收藏**：固定报表列表支持按名称 / 表名检索，常用报表点星标收藏置顶；「最近查询历史」每条新增「存为报表」，历史里跑出的好查询一键转为正式报表。
- **重复字段拦截**：同一字段重复加入指标区会提示并拦截（需不同聚合方式时先移除再加），不再产出重复口径的 SQL。
- 新增服务端字段取值接口（`GET /api/datasources/:id/flex-column-values`）：取值下拉恒走只读安全执行层（表白名单 + 敏感列剔除 + 行级权限），仅 ADMIN/ANALYST 可用。
