## 六、遗留事项与下一季度建议

1. **超长文件继续收敛**：27 个 >500 行文件（重点：§4.3 TOP5），沿用本轮验证过的手法（Hook 收敛 + 子组件抽离 + JSX 保真校验）。
2. **主版本升级评估**（本轮 range 内未升，需单独立项）：`express 5` / `vite 8` / `vitest 5` / `typescript 7` / `lucide-react 1.x` / `motion 13` / `esbuild 0.28` / `@types/node 26` / `@vitejs/plugin-react 6` / `@types/express 5`。
3. **eval/scripts 的 any 269 处**：CLI 评测脚本与测试文件的合法豁免（永久），随脚本迭代自然收敛，不占用债务额度。
4. **npm update 的 arborist 兼容问题**：npm 10.9.8 在 vitest peer 解析处有已知 bug（`Cannot read properties of null (reading 'edgesOut')`），本轮以 `--legacy-peer-deps` 规避；下一次依赖窗口前建议评估 npm 版本或改用其他包管理器。
5. **前端测试覆盖**：src 侧覆盖率仍偏低（基线报告同项），可纳入下一季度质量计划。
