# 智能问数分析系统 · 更新日志

> 本日志按版本记录系统的主要更新内容，供用户备查。各版本的具体操作方法见「使用指南」；完整技术细节见《系统功能说明书》变更记录（仅供管理员与评审参考）。

## v0.9.51（2026-09-12）

- 修复浅色主题下「Agent 编排」内容看不清的问题：多能力编排计划卡、执行结果卡的标题与步骤序号，以及「Agent 编排」开关的选中文字，此前在浅色背景下与背景色相近、难以阅读；现已按浅色主题重新配色（深紫红文字 + 淡粉底），深浅主题下均清晰可读。

## v0.9.50（2026-09-12）

- 系统管理升级为「左侧分类导航 + 右侧内容区」双栏控制台：7 个分类按「账号与权限 / 治理与审核 / 运维与系统」三域分组一屏尽览，切换分类时右侧内容独立滚动并自动回到顶部，不再需要横向滚动查找入口。
- 异常巡检整合进系统管理：系统管理新增「异常巡检」分类（管理员），与左侧导航「异常巡检」页功能完全一致（同一组件双入口）；各角色的巡检查看与管理方式保持不变。
- 补充巡检分类在浅色主题下的配色适配，深浅色切换下左栏导航显示正常。

## v0.9.49（2026-09-12）

- 看板图表新增「高级分析」（图表卡片右上角趋势线图标，管理员/分析师可用），一个入口三件套：
  - **时序预测**：选择指标列后一键预测未来 3/6/12 期的数值与波动区间（约 80% 置信范围），自动从移动平均/线性回归/季节分解中挑最合适的模型并附中文趋势解读，适合不良率、回收率、投放金额等指标的提前预判；
  - **多维归因**：选择维度/时期/指标列后，自动取最新两期数据按维度（如区域×机构×账龄）拆解「谁拉高、谁拉低」，按影响大小排序并给出贡献占比与核查建议；
  - **情景推演**：对图表固化时保存的查询口径输入「如果……会怎样」的假设（如"收紧某区域投放 20% 后如何变化"），系统自动改写条件并对比执行两种口径，量化给出变化幅度与口径提醒。
- 问数新增「Agent 编排」开关（在「先制定计划」旁）：开启后提问不再是单步执行，而是先由系统规划完整分析链路（例如：先查数 → 再预测趋势 → 再拆解变化原因），你确认后自动按顺序逐步执行并汇总结果；适合"既要数据、又要预测、又要归因"的复合分析诉求，与「先制定计划」开关互斥（开启一个会自动关闭另一个）。

## v0.9.48（2026-09-12）

- 新增「异常巡检」（左侧导航新入口，管理员/分析师可创建计划）：把重要数据源交给系统定期盯着——设定巡检周期（每小时/每 6 小时/每 12 小时/每天/每周）后，系统按期自动扫描该数据源最新的真实数据报表，指标出现异常波动（如增长率骤升、不良率骤降）自动记录预警；巡检卡片可看上次/下次巡检时间与最近异常数，支持「立即巡检」、暂停/启用、运行历史查看与删除，无需人工反复查数。
- 报表导出新增 Excel 与 Word：可视化决策报表与问数报告中心的简报均可「下载 Excel 表格」（含高管摘要/核心 KPI/图表三个工作表）与「下载 Word 报告」（图文混排，含摘要、KPI 表格、图表与结论建议），适合数据二次加工与正式报送归档。
- 问数结果「查看生成的 SQL」升级为三级数据溯源：弹窗改为「指标口径卡 → 表关联图 → SQL/原始数据」逐级展开——先看本次结果命中的语义指标（权威口径、来源表、审批状态与版本历史），再看数据来自哪些表、如何关联，最后看完整 SQL 与查询返回的原始数据行，结果可信度一眼可查。
- 语义指标治理延伸到使用侧：指标口径卡中直接展示指标的审批状态（待审批/已生效/已驳回/已停用）与版本历史（谁在何时创建/审批/变更过口径），核对数据时可同步确认口径的治理状态。

## v0.9.47（2026-09-10）

- 运维可靠性升级：服务停机/重启（部署、扩容、回滚）时不再直接掐断正在处理的提问——先停止接收新请求、等待在途请求完成（最长 10 秒，可用环境变量 SHUTDOWN_TIMEOUT_MS 调整）后再退出，升级窗口内正在生成的问数与报表不受影响。
- 健康检查升级为两级：新增存活检查（/api/health/live，判断进程是否存活）与就绪检查（/api/health/ready，自动探测数据库、缓存连接是否正常以及是否正在停机）；容器编排/负载均衡可据此在依赖异常时自动摘除流量、停机时平滑下线。
- 系统监控端点（/metrics，面向运维）安全加固：访问令牌比较改为防时序侧信道方式；生产环境未配置 METRICS_TOKEN 时启动即告警（建议管理员按部署文档配置）。
- 安全修复：升级依赖组件消除 express 链路的 2 项拒绝服务漏洞；报表导出新增「图表图片真实 PNG 二进制校验」，伪造/恶意构造的图片数据将被安全丢弃并自动回退为文字展示。
- CI 流水线新增端到端冒烟作业：每次代码提交自动校验登录与主界面渲染、核心 API 契约、知识库链路，回归问题更早发现。

## v0.9.46（2026-09-10）

- 新增「Fallback 效果分析」看板（系统管理，面向管理员）：Rule-Based 与「人工审核 + 示例增强」两类降级策略的成功率、延迟对比与实验记录可查询追溯，支持时间范围筛选与实时刷新。
- 系统管理界面优化：各子面板统一补卡片标题条、样式对齐决策数据看板，各模块可一眼区分。
- 修复 Fallback 对抗训练闭环 9 处断链：此前「人工审核 → 示例注入 → 简化提示词检索」链路存在多处未真正打通（审核提交、示例入库、策略分支未接通等，属 v0.9.44/v0.9.45 遗留），现已端到端修复——问数失败样本经审核采纳后真实进入示例库，并在后续问数的降级重试中生效。

## v0.9.45（2026-09-10）

- 新增「Fallback 人工审核队列」（系统管理 → Fallback 审核，面向管理员）：问数失败且自动降级仍未成功的困难问题自动进入审核队列，管理员可修正 SQL 并采纳为标准示例；采纳的示例自动注入示例库（Few-Shot），后续相似问题命中示例后一次成功率提升——形成「失败样本 → 人工修正 → 自动学习」的闭环。
- 审核队列支持优先级排序：按积压时长、同题高频失败、查询复杂度、数据源冷热、用户角色加权综合评分，高价值样本优先处理。
- 新增 Fallback 策略 A/B 实验框架：每次自动降级按用户确定性分组（规则式 vs 人工审核 + 示例增强），持续对比两类策略的成功率与延迟。

## v0.9.44（2026-09-10）

- 问数失败自动降级重试（Fallback 对抗训练机制）：复杂问题一次生成/执行失败时，系统自动依次尝试「规则式修正（时间范围、聚合意图识别）→ 简化提示词（精简 Schema + 示例引导）」两级降级策略，减少直接报错；失败与降级过程全程留痕（策略、耗时、困难样本自动收集），供持续优化。

## v0.9.43（2026-09-09）

- 智能问数「专家角色」内容升级：内置 5 个专家角色（不良资产风险管理 / 不良资产客户分析管理 / 专业财务分析 / 资深不良资产处置 / 默认金融数据分析）的提示词由一句话身份设定升级为完整「角色定位 + 四大分析维度框架 + 输出要求 + 术语规范」（按业务方提供的角色定义改写），AI 解读的分析深度与专业术语使用显著提升；触发关键词按行业术语扩充（如风险类新增「敞口/集中度/劣变/抵质押」、客户类新增「买家/意向/转化/漏斗」、财务类新增「三费/周转/应收/存货」、处置类新增「拍卖/重组/转让/IRR」）；角色提示词长度上限由 500 字提升至 2000 字。存量部署升级后，内置角色内容会在首次启动时自动刷新至最新版（管理员此前对内置角色的状态与优先级调整保留；刷新后的再编辑不会被覆盖）。

## v0.9.42（2026-09-08）

- 修复明细表/图表中个别派生列仍显示英文列名的问题（如「recovery_ratio_pct」）：此类列是 AI 计算生成的派生指标，不在数据源中文映射中，此前按原样展示。现双重保障：AI 生成侧要求所有派生列必须给出中文业务名；服务端兑底侧对英文列名按词根推断中文表头（如 recovery_ratio_pct → 回收比率（%）），词根无法识别的保持原值、不编造名称。

## v0.9.41（2026-09-08）

- 修复 AI 归因解读不按所选金额单位表述的问题：此前选择「亿元」等单位后，AI 解读仍可能按数字规模自行换算（如把 54505.36 亿元写成「5.45 万亿」、把原值写成「3776.91 百万」）。现解读生成全程显式携带所选单位并禁止任何换算改写，智能问数与可视化报表同步生效；同时修复「金额原值保护」规则与界面单位选择之间的指令冲突，确保数值换算稳定按所选单位执行。

## v0.9.40（2026-09-08）

- 新增「专家角色」管理（系统管理 → 专家角色，仅管理员维护）：智能问数会按提问内容自动匹配专家视角（如风险管理、客户分析、财务分析）生成解读。现可维护各角色的名称、触发关键词与角色提示词原文，也可新增自定义专家角色，保存即时生效——提问命中关键词即自动启用对应视角，未命中时使用「默认分析师」兜底；内置角色可编辑不可删除，默认兜底角色始终生效、不参与关键词匹配、不可停用。

## v0.9.39（2026-09-08）
