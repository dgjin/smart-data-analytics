# 智能问数分析系统 · 更新日志

> 本日志按版本记录系统的主要更新内容，供用户备查。各版本的具体操作方法见「使用指南」；完整技术细节见《系统功能说明书》变更记录（仅供管理员与评审参考）。

## v0.9.43（2026-09-09）

- 智能问数「专家角色」内容升级：内置 5 个专家角色（不良资产风险管理 / 不良资产客户分析管理 / 专业财务分析 / 资深不良资产处置 / 默认金融数据分析）的提示词由一句话身份设定升级为完整「角色定位 + 四大分析维度框架 + 输出要求 + 术语规范」（按业务方提供的角色定义改写），AI 解读的分析深度与专业术语使用显著提升；触发关键词按行业术语扩充（如风险类新增「敞口/集中度/劣变/抵质押」、客户类新增「买家/意向/转化/漏斗」、财务类新增「三费/周转/应收/存货」、处置类新增「拍卖/重组/转让/IRR」）；角色提示词长度上限由 500 字提升至 2000 字。存量部署升级后，内置角色内容会在首次启动时自动刷新至最新版（管理员此前对内置角色的状态与优先级调整保留；刷新后的再编辑不会被覆盖）。

## v0.9.42（2026-09-08）

- 修复明细表/图表中个别派生列仍显示英文列名的问题（如「recovery_ratio_pct」）：此类列是 AI 计算生成的派生指标，不在数据源中文映射中，此前按原样展示。现双重保障：AI 生成侧要求所有派生列必须给出中文业务名；服务端兑底侧对英文列名按词根推断中文表头（如 recovery_ratio_pct → 回收比率（%）），词根无法识别的保持原值、不编造名称。

## v0.9.41（2026-09-08）

- 修复 AI 归因解读不按所选金额单位表述的问题：此前选择「亿元」等单位后，AI 解读仍可能按数字规模自行换算（如把 54505.36 亿元写成「5.45 万亿」、把原值写成「3776.91 百万」）。现解读生成全程显式携带所选单位并禁止任何换算改写，智能问数与可视化报表同步生效；同时修复「金额原值保护」规则与界面单位选择之间的指令冲突，确保数值换算稳定按所选单位执行。

## v0.9.40（2026-09-08）

- 新增「专家角色」管理（系统管理 → 专家角色，仅管理员维护）：智能问数会按提问内容自动匹配专家视角（如风险管理、客户分析、财务分析）生成解读。现可维护各角色的名称、触发关键词与角色提示词原文，也可新增自定义专家角色，保存即时生效——提问命中关键词即自动启用对应视角，未命中时使用「默认分析师」兜底；内置角色可编辑不可删除，默认兜底角色始终生效、不参与关键词匹配、不可停用。

## v0.9.39（2026-09-08）

- 铁律「表头及说明必须中文」增加服务端强制兜底：此前该铁律仅靠提示词约束模型，当模型未遵守时，表格表头、图表轴名/标题、推导过程与 AI 解读/洞察/KPI/建议追问中仍可能残留英文字段名。现系统在返回结果前自动将残留的英文表名/列名替换为数据源中维护的业务中文名，即使模型输出不合规也能保证界面呈现全中文；同时解读生成提示词新增英文标识符禁令，双重保障。

## v0.9.38（2026-09-08）

- 智能问数结果新增「全屏」显示：结果区顶部点击「全屏」按钮后，KPI 指标、AI 归因分析、图表与明细数据在整屏内完整呈现——图表自动加高、明细数据每页展示 50 行（原为 10 行），顶部吸顶栏显示本次提问原文；按 Esc 键或点「退出全屏」返回对话，图表类型切换与固化到看板等操作在全屏内同样可用。

## v0.9.37（2026-09-07）

- 内部文档质量建设：建立统一代码注释规范并对问数、报表、图表、看板等核心链路的代码注释进行了系统完善，无界面功能变化。

## v0.9.35（2026-09-07）

- 新增「铁律规则库」（系统管理，仅管理员维护）：按数据源定义本数据源所有问数必须遵守的强制规则（如「禁止跨法人统计」「只取最新一期数据」）；生效中的规则对每次智能问数与报表生成强制生效，优先级高于样例与知识库；支持启停与 JSON 备份导入导出（冲突跳过/覆盖、可预检）。

## v0.9.34（2026-09-07）

- 数据源管理新增「导入本地 CSV / Excel / JSON」：上传文件即可把真实数据导入系统，随后像数据库数据源一样智能问数、生成报表、做灵活查询；表头含密码/身份证等敏感词的列自动剔除并在导入提示中列明。

## v0.9.33（2026-09-07）

- 语义指标与 SQL 样例库支持 JSON 备份导入导出（管理员），迁移环境或跨团队共享时可直接导入；同名冲突可跳过或覆盖，支持先「预检」再正式导入。
