# 智能问数分析系统 · 用户使用指南

> 本指南面向系统使用者，回答"怎么用"。完整功能规格与技术细节见《系统功能说明书》（仅供管理员与评审参考）。
> 
> **适用版本**: NL2SQL Pro v0.9.8 (v0.4.16)  
> **最后更新**: 2026-09-01

---

## 1. 三分钟上手

第一次使用，只需三步：

1. **登录**：打开系统首页，输入管理员分配的账号密码。首次登录如被要求修改初始密码，请按提示完成。
2. **选数据源**：在页面顶部的数据源切换器中，选择你要分析的数据（例如某个业务库或报表）。
3. **用中文提问**：在底部输入框直接输入你想了解的问题，例如「各业务类型的资产规模占比是多少？」，回车等待结果。

几秒钟到两分钟内，系统会依次展示：**生成的 SQL → 真实数据表 → 自动图表 → 文字解读**。至此你已完成第一次智能问数。

## 3. 智能问答：怎么问、怎么看

入口：左侧导航「智能问答与查询」。这是系统的核心功能。

### 3.1 提问技巧

- **说清指标和维度**：「各机构本年投放金额排名」比「投放情况怎么样」更容易得到准确结果。
- **带上时间与口径**：例如「2026 年上半年」「按月末快照」。
- **一次问一件事**：复杂分析建议拆成多轮提问，或使用「深度分析」开关。
- **善用示例**：新对话的欢迎语中会列出当前数据源的示例问题，点击即可提问。
- **支持复杂分析**：可直接询问同比环比、TOP-N 占比、条件聚合等复杂问题，系统会自动匹配最佳分析方式。

### 3.2 看懂一次回答

每次回答通常包含四部分：

- **SQL 语句**：系统生成的真实查询（可展开查看，供核对口径）；
- **数据表**：查询返回的真实记录；
- **图表**：系统按数据特征自动推荐柱图/折线/饼图等；
- **文字解读**：基于真实数据得出的要点结论。

点击消息中的「推导过程」，可以回放这次提问的完整处理步骤（如何选表、生成 SQL、执行耗时等），便于追溯。

**特殊标识说明**：
- 🟢 **模板命中**：绿色高亮表示系统使用了预设的分析模板（如同比环比/TOP-N 占比），结果更精准
- 📊 **知识库引用**：黄色高亮表示系统参考了业务知识库的口径定义
- 🔴 **结果校验失败**：当结果为空或异常时，系统会自动重试生成新的 SQL

### 3.3 系统反问你时（歧义澄清）

当问题有多种理解时，系统会给出候选理解让你选择，而不是擅自猜测。点击最符合你意图的一项即可继续。

### 3.4 常用开关与工具（输入区附近）

- **报告模式**：开启后提问直接生成完整分析报告，见第 4 节。
- **计划模式**：开启后系统先给出分析计划（分几步、查哪些表），你批准后才真正执行，适合重要分析前确认思路。
- **深度分析**：复杂问题开启后会自动做多步骤数据清洗再分析，耗时更长但结果更精细。
- **金额单位**：可切换 亿元/百万元/万元/元，全篇结果（表格、图表、解读）按同一单位展示。
- **模型选择**：输入框旁可切换 AI 模型，一般保持默认即可；不同模型结果互不影响。

### 3.5 让系统越用越准

- 结果正确时点 **赞**：该问答会自动沉淀为样例，以后类似问题更准；
- 结果不对时点 **踩**：系统会记录并避免重复同类错误。

### 3.6 历史对话

- 问数页可打开「历史对话」面板：按关键词搜索、一键重问、单条删除；
- 「导出」可将当前数据源下的对话导出为 Markdown 存档；
- 「重置对话」只清空当前数据源下的记录，不影响其他数据源。

## 4. 一键生成分析报告（报告模式）

适合定期产出经营分析报告，无需逐条提问。

1. 在问数输入区开启「报告模式」开关；
2. 在模板下拉框中选择报告模板（如综合经营分析、资产质量与风险监控等），或保持「智能推断」由系统按提问自动组织；
3. 输入分析主题（例如「分析本季度经营情况」）并提交；
4. 生成完成后，对话中会出现报告卡片，点击「查看完整报告」进入详情页。

**报告中心**：左侧导航「问数报告中心」集中管理你生成的所有报告，支持查看、导出 PDF/PPT、删除。管理员可查看全员报告。

> 管理员还可在「系统管理 → 报告模板」中新增自定义模板（章节标题 + 分析提示词 + 图表类型），无需编写代码。

## 5. 可视化决策报表

入口：左侧导航「可视化决策报表」。面向高管的一页纸简报。

- **生成**：选定数据源后点击生成，系统自动产出摘要、关键指标、图表组与结论建议；
- **同/环比**：时间序列图表支持一键叠加同比/环比基线（分类维度图表不支持）；
- **点击下钻**：点击图表中某个柱子/数据点，可查看该维度值对应的明细记录（最多 50 条）；
- **批注**：可在图表下方添加评论，供团队协同；
- **导出**：支持下载 PPT（自动排版分页）与 PDF（A4 竖版/横版可选）。

## 6. 决策数据看板

入口：左侧导航「决策数据看板」。适合日常巡检与固定指标监控，所有角色可见。

- 看板图表可来自问数结果或灵活查询的「固化」操作；
- 带「自动更新」角标的图表会定期检测底层数据变化，数据更新后自动刷新，无需人工重跑。

**语义指标直查**（管理员与分析师）：在看板顶部选择数据源与已登记的语义指标，可按需勾选切分维度，一键查出权威口径结果并固化到看板。金额类指标默认跟随右上角全局金额单位统计（如全局选「万元」，直查结果即按万元口径），面板内也可单独选择单位覆盖；计数类指标与「元」原值口径不换算，结果旁会标注实际生效单位。

## 7. 灵活查询：不写 SQL 定制报表

入口：左侧导航「灵活查询」（管理员与分析师可用）。

1. 选择数据表；
2. 从字段列表把字段拖入（或点击加入）「分组维度」和「聚合指标」；
3. 按需添加筛选条件、排序、行数上限；
4. 点击执行，查看图表与明细数据。

进阶能力：多表关联（配置 JOIN）、去重计数、区间筛选（BETWEEN）、聚合后过滤（HAVING）、占比计算、透视表、CSV 导出。满意的查询可「固化到看板」或「保存为固定报表」下次一键载入。

## 8. 数据管理（仅管理员）

入口：左侧导航「数据源与 Schema」。

| 子页签 | 用途 |
|--------|------|
| 数据源管理 | 新增/编辑/删除数据源（MySQL、PostgreSQL、Greenplum、CSV、API、JSON），测试连接，启停问数 |
| Schema 查看器 | 查看表结构、字段含义、行数 |
| 数据血缘 | 查看数据表之间的流向与依赖 |
| 知识库 | 维护业务术语与指标口径，智能问数与可视化决策报表生成 SQL 时自动检索注入，让模型"懂业务" |
| SQL 样例库 | 维护「问题-SQL」训练样例；支持粘贴多条 SQL 批量导入，由 AI 反推问题 |
| 语义指标 | 登记关键指标的权威口径（名称、同义词、聚合表达式） |
| 技能库 | 预设复杂分析的标准化流程，确保每次执行结果一致 |

**提升问数准确率的三个抓手**（按优先级）：

1. **知识库**：把业务口径、易混淆字段含义写清楚；
2. **SQL 样例库**：把高频问题与标准 SQL 登记为样例；
3. **语义指标**：在「数据源管理」中为关键指标登记权威计算口径，保证全系统口径一致。

**行级权限**：可在数据源上配置数据过滤规则（例如限定某机构范围），用户查询时被自动约束，只能看到权限内数据。

**外部知识源**：知识库面板底部可接入企业外部知识服务，作为问数的补充知识来源。

## 9. 系统管理（仅管理员）

入口：左侧导航「系统管理」。

- **用户管理**：新增用户、分配角色、停用账号、重置密码；
- **Token 用量**：按时间范围查看每个用户的 AI 调用量与成功率，支持按模型汇总，用于成本管理；
- **报告模板**：维护报告模式可用的模板，预设模板不可删除，自定义模板可自由增删改；
- **部门权限**：按部门管理数据源访问授权与审批。

## 10. 常见问题

**Q：回答不准、字段对不上，怎么办？**  
A：先换更明确的问法（说清指标、维度、时间）；仍不准可点踩反馈；长期改进请联系管理员补充知识库口径、登记 SQL 样例或语义指标。

**Q：为什么同样的问题第二次提问秒回？**  
A：系统对 10 分钟内的相同问题启用结果缓存，直接复用上次的真实查询结果，属正常现象。

**Q：结果里出现「演示数据」标识是什么意思？**  
A：说明 AI 服务或数据库暂时不可用，系统展示了带明确标识的示例数据以保证界面可用，**请勿据此决策**；稍后重试或联系管理员检查服务。

**Q：提问提示超时？**  
A：复杂问题在 AI 模型上可能需要 1-3 分钟，请耐心等待；频繁超时请联系管理员检查 AI 引擎状态（侧边栏底部有引擎运行指示灯）。

**Q：为什么有些图表不能做同/环比？**  
A：同/环比仅对时间序列维度（年/月/日）开放；机构、业务类型等分类维度没有"上一个周期"的概念，系统会自动禁用。

**Q：看不到「智能问答」入口？**  
A：你的角色可能是只读用户（VIEWER），该角色仅可查看报表与看板。需要问数权限请联系管理员。

**Q：忘记密码 / 需要开通账号？**  
A：请联系系统管理员在「系统管理 → 用户管理」中重置或开通。

## 12. 新版本功能亮点（v0.4.16）

本次更新主要增强了复杂 SQL 分析能力与浏览器兼容性：

### 🚀 复杂 SQL 增强
- **同比环比自动识别**：直接询问「今年各季度与去年对比」，系统自动生成复杂的 CTE 查询

### 📚 辅助功能
- 新增 10 条复杂场景 SQL 样例库，覆盖常见分析需求
- 前端标注「模板命中」与「知识引用」状态，透明度提升
