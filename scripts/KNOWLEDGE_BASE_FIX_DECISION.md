## ✅ 推荐方案：纯文本标记替代法

### 实施方案
将 Markdown 代码块全部替换为易读的纯文本标记：

**原始格式** (❌ 导致编译错误):
```typescript
content: `## SQL 示例
\`\`\`sql
SELECT * FROM table WHERE BB = '1'
\`\`\``
```

**修复后格式** (✅ 无语法错误):
```typescript
content: `## SQL 示例
[SQL]
SELECT * FROM table WHERE BB = '1'
[/SQL]`
```

或更友好的中文标记：
```typescript
content: `## SQL 示例
【SQL】
SELECT * FROM table WHERE BB = '1'
【/SQL】`
```

### 实施步骤
1. 批量替换所有 ```sql...``` → [SQL]...[/SQL]
2. 批量替换所有 ``` → [/MARKDOWN]
3. 批量替换行内 \`code\` → 【代码】code【代码】
4. 验证编译通过
5. 同步更新前端渲染逻辑（可选：添加 HTML 标签转换为 Markdown 高亮显示）

### 预计效果
- **编译错误**: 1,148 个 → 0 个 ✅
- **开发时间**: 约 30 分钟
- **风险等级**: 极低（仅文本替换，逻辑不变）
- **可读性**: 保持良好（清晰区分代码块）
