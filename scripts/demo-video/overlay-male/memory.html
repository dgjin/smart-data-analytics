纠错记忆闭环
点踩 → 候选 → 审核 → 召回
  • 1
    点踩反馈
    选择错误类型（选表 / 字段 / 口径 / 理解 / 其他），补充期望口径
  • 2
    候选沉淀
    同问题幂等合并，生成待审核的纠正候选
  • 3
    人工审核
    管理员在「系统管理 → 记忆管理」确认内容与期望 SQL
  • 4
    召回注入
    相似问题优先注入纠正口径（阈值 0.45，最多 2 条）
  • 5
    置信度回写
    点赞 +0.05 / 点踩 −0.20，90 天未命中且低置信自动归档
↻反馈 → 候选 → 审核 → 召回 → 再反馈
off · 默认关闭 → shadow · 影子留痕不注入 → on · 按用户灰度（20% 起） 默认行为与接入前完全一致，回滚只需置回 off
